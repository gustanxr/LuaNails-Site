# LuaNail

Landing page da LuaNail feita com Next.js, React, TypeScript e Tailwind CSS.

## Começar

```bash
npm install
npm run dev
```

Abra [http://localhost:3000](http://localhost:3000) no navegador.

## Personalizar conteúdo

- O número e a mensagem inicial do WhatsApp ficam no início de `app/page.tsx`, na constante `whatsapp`.
- Os serviços e os itens da galeria também estão no início de `app/page.tsx`.
- Troque as imagens de demonstração da hero, da seção Sobre e da galeria por fotos autorizadas da LuaNail.
- Atualize a descrição da profissional quando ela fornecer sua história, localização e diferenciais.

As imagens externas atuais são apenas inspirações temporárias e precisam de conexão com a internet para carregar.
